## AWS 강의 내용 정리
### Global Infra

1. Region : AWS가 서비스를 제공하는 도시
2. Availabllity Zone (가용영역) : 가용성 있는 서비스, 이중화를 위해서
3. Edge Location : 사용하는 리전 근처에 있는 시설물. 요청 응답을 빠르게 내려주기 위해 ex) DNS (Route 53), CDN (CloudFront), Lambda edge

### AWS VPC

- 가상의 사설 네트워크
- 일반적으로 사설망에는 인터넷에서 접근할 수 있는 방법이 제한되어 있다.
- 반드시 Region 안에 생성됨
- 사설 IP 대역

### subnet

- VPC보다 더 작은 단위로 IP 대역을 나눔
- VPC의 내부 리소스를 그룹핑

1. Internet Gateway (igw-idxxx) = NAT + 
2. Public IP

4. 보안 그룹 정의 

### Security Group vs NACL

- Security Group : 인스턴스 단위로 적용되는 보안 규칙
    - 허용(Allow) 규칙만 지원하고, Default 규칙은 All Deny
    - 상태 저장. 인바운드 트래픽을 허용하면 해당 응답 트래픽이 자동으로 허용
- NACL : 서브넷 단위로 적용되는 보안 규칙
    - 허용(Allow)과 거부(Deny) 규칙을 모두 지원. Default 규칙은 All Open
    - 상태 비저장. 인바운드와 아웃바운드 트래픽을 각각 별도로 정의해야 함.
