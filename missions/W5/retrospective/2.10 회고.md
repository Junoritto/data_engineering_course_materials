### On Heap Memory

- Storage Memory : RDD 캐시가 일어나고, unroll data가 일어나는 곳. 설정할 수 있음.
- Execution Memory: 적게 설정되면 오버헤드가 많이 발생. shuffle, join, sort, agg등이 일어나는 곳
- User Memory
- Reserved Memory

### If your executor memory is 5 GB,

1. spark.executor.memory = 5 GB
2. memory overhead = max(10% of spark.executor.memory, 384 MB)
3. max( 5 GB * 1024 MB * 0.1, 384 MB) = max(512 MB, 384 MB) = 512 MB.
4. heap space = 5 GB - 512 MB = 4608 MB
5.  reserved memory = 300 MB
6. heap space - reserved memory = 4308 MB
7. spark.memory.fraction = 0.6 (default)
8. 4308 MB * 0.6 = 2585 MB
9. spark.memory.storageFaction = 0.5 (default)
10. 2585 MB * 0.5 = 1293 MB
11. user memory = (1- spark.memory.fraction) * 4308 MB = 1723 MB

데이터 셔플을 최대한 줄여야 한다.

### repartition vs coalesce

- repartition
    - 데이터를 균등하게 분배해야 할 때
    - shuffle이 허용되는 경우
- coalesce
    - 파티션 수를 줄여서 최적화할 때
    - shuffle을 최소화 시키고 싶을 때
